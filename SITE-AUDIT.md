## 3. Page-by-Page Structure

### Home (`/`)
1. Top announcement banner, 3-Month Digital Well-Being Challenge (🌿 repeating)
2. Hero, "HEAL GROW INSPIRE"
3. Mission statement
4. Statistics (children supported)
5. "Be the Change" CTA, Donate / Volunteer / Fundraise

7. News / blog feed
8. Testimonials, "Real People, Real Change"

### About Us (`/about-us/`)
1. Banner → 2. About + founder photo → 3. Founder's message (Ishita Gupta) → 4. Mission & Vision → 5. Four focus areas → 6. How We Work → 7. Join the Cause CTA → Footer.

### Get Involved (`/get-involved/`)
1. Banner → 2. Mission (Heal/Grow/Inspire) → 3. "Why Get Involved" (3 concepts + landscape photos) → 4. "Ways to Make Impact" (Volunteer / Give / Partner / Share) → 5. "Together, We RehVamp the Future" CTA → Footer.

### Contact (`/contact-us/`)
Heading "Let's heal, grow, and inspire together" → contact details → form (Name, Email, Message, Send) → Footer.

### Save Gaza's Children (`/save-gazas-children/`)
Hero w/ "Take Action" → crisis stats ("The World's Deadliest Place to Be a Child") → "Act with Purpose" 4 intervention areas (Healthcare & Nutrition, Water & Sanitation, Safe Healing Spaces, Education & Resilience) → secondary CTA. Emotional/urgent tone, humanitarian photography.

### 3-Month Challenge (`/3-month-challenge/`)
Intro → 3 monthly phases (Month 1 HEAL, Month 2 GROW, Month 3 INSPIRE) → Rewards (Third Space Mayfair, AIRE Ancient Baths, wellness book bundles) → Footer.

### Phase 1: HEAL (`/phase-1-heal/`)
Intro/benefits → activities → 4-step process (Join → Track → Upload → Reflect) → long submission form (10–12 min) → participant rules & consent policy.

### Emergency Exit Guidance (`/emergency-exit-guidance/`)
Humanitarian travel coordination: route planning, private airlift, visa facilitation, embassy coordination, shelter. 24/7 WhatsApp, emergency assistance form, exit routes (Saudi/Oman/onward), emergency numbers.

### Blog post template
Title → hero image → body (sectioned w/ subheadings, blockquote, numbered list) → date + tags → next/prev nav → sidebar (related posts + email signup) → share buttons → footer.

## 5. Notes for the Redesign
- Strong, consistent **Heal / Grow / Inspire** narrative, keep as the backbone.
- Site mixes three quite different missions: **children's charity**, a **digital well-being challenge** (with forms + prizes), and **acute humanitarian/emergency** work (Gaza, exit guidance). The redesign should give each a clear home in the IA without diluting the core children's-charity identity.
- `/builder-2/` looks like a stray page, confirm before carrying over.
- Current stack is WordPress; decide whether the redesign stays on WP or moves to a custom build.
- Exact colors/fonts live in external CSS (not inline), define a fresh, documented design system rather than reverse-engineering the old one.
